
# 🛒 ShopCart – Modern E-Commerce Website with React & Vite

**ShopCart** is a sleek and high-performance e-commerce platform built using **ReactJS** and **Vite**. Designed with clean UI, modular components, and a focus on scalability, it’s a great starting point for learning modern frontend development or launching your own shopping app.


---

## 🚀 Key Features

- ⚡ **Fast Development:** Built with React + Vite for lightning-fast load times
- 🎨 **SCSS Styling:** Organized, modular SCSS for clean and maintainable styles
- 🛍️ **Product Listing:** Dynamic product display with future-ready filter support
- 🧺 **Cart System:** Real-time shopping cart with item tracking
- 💳 **Payment Ready:** Placeholder structure for seamless future integrations
- 🧩 **Scalable Codebase:** Component-driven structure for easy scaling
- 🧹 **Clean Code Standards:** ESLint & Prettier pre-configured for consistency

## ⚙️ Getting Started

Clone the repo and install dependencies:

```bash
git clone https://github.com/CryptoMinds-Dev/ShopCart.git
cd ShopCart
npm install
```

Start the development server:

```bash
npm run dev
```

---

## 📦 Build & Deployment

Build the project for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

---

## 🧪 Code Quality

Run ESLint for code analysis:

```bash
npm run lint
```
